# AGENTS.md — read this first (single source of truth for agents)

This is the **speciesOT** cross-species single-cell optimal-transport project: predict
human cells from mouse cells (species transport) via **IMPACT_CellOT** (CellOT/ICNN-OT
in a shared scGen autoencoder latent space), with **scGen** as the baseline. Eventual
goal: compose a species transport with a drug-effect transport (BCG line) to predict
human-treated cells. This file is self-contained — you do not need any other doc to
start. Deeper context is linked where useful.

## Hard rules (do not violate)
- **Never `git commit` or `git push` unless the user explicitly asks.** Work lives
  uncommitted on `main`; the `josh` remote (mentor's repo) is diverged — never force-push.
- **Everything routes through `./hub`** (CLI in [`speciesOT/hub/`](speciesOT/hub/)):
  `list`, `scorecard`, `show`, `compare`, `prep`, `generate`, `metrics`, `handoff`,
  `vault`, `card`. The hub **never auto-submits** sbatches — it prints the chain; the
  human (or you, only when asked) submits. The safety boundary is at submission.
- **Two conda envs.** `CellOT` (torch 1.11; runs the hub, training, eval) and `analysis`
  (scanpy ≥1.12; for `./hub prep` HVG + notebooks). `cellot` is **not pip-installed** —
  set `PYTHONPATH=<repo>/cellot/cellot_gpu` to import it. The `./hub` wrapper
  auto-activates `CellOT`.
- **GPU jobs** use `CellOT_gpu` (torch 2.x, H100/H200 on `gpu_requeue` via `--constraint=h100|h200`).
  Legacy `CellOT` (torch 1.11) remains for CPU; V100 no longer required once `CellOT_gpu` is validated.
- **Don't full-load the 43 GB `tabula_*_all.h5ad` atlas** — use the backed prep path
  ([`speciesOT/hub/prep_backed.py`](speciesOT/hub/prep_backed.py), `source_backed: true`)
  as a high-mem batch job, never on a login node.
- **Judge models by the north-star, not raw R²/MMD** (see below).
- **`specs/*.yaml` are the source of truth** for experiment intent. `./hub spec dump` is
  lossy for intent fields (assay_filter, datasplit_stratify, device, …) — clone the spec
  file instead of re-dumping when those matter.

## The north-star metric (how we judge "are we improving?")
- **One headline:** `frac_gap_closed_decoded` — fraction of the mouse→human MMD gap
  closed, measured in the **AE-decoded frame** (apples-to-apples, where the model's
  output actually lives). This is what `./hub scorecard` sorts on.
- **Two guardrails:** `frac_r2_closed_decoded` (did the mean come out right?) and
  `mean_js` (per-gene Jensen-Shannon ≈ symmetric KL — the metric to use when the
  question is phrased in KL terms).
- **Ignore raw `frac_gap_closed`** as a ranking metric — it mixes decoded-imputed vs
  raw-treated and flips sign for measurement reasons (the "AE round-trip tax"). The hub
  keeps it only as a diagnostic.
- **The frozen benchmark:** model-version comparisons are made on the v08 OOD cuts
  (`hvg_pearson_residuals_{m1,m2,a_uncapped}_v08_ood`) at fixed seed (`random_state=0`)
  and fixed `ncells` (30/50/80, headline at 80). "Did this help?" is always answered on
  these same cells via `./hub scorecard`.
- Full rationale + the AE round-trip explanation: [`docs/conceptual_framework.md`](docs/conceptual_framework.md) §5.9.

## One-command experiment flow
```bash
./hub prep specs/<spec>.yaml        # build the dataset .h5ad (analysis env, auto-shelled)
./hub generate specs/<spec>.yaml    # write configs + sbatches; prints the submit chain
# copy-paste the printed sbatch chain to submit (afterok deps are wired)
# after training + eval finish:
./hub metrics <run_id>              # compute raw + decoded metric sidecars
./hub scorecard                     # the leaderboard, ranked by the north-star
```

## Definition of done (for agents working here)
- New analysis scripts go in `scripts/` or `cellot/cellot_gpu/scripts/`; new metrics flow
  through the **sidecar** pattern (a CSV beside `evals.csv` that `readers.py` picks up) —
  do not edit upstream `evaluate.py` to add metrics.
- **Metric atlas canvases:** after a model is scored (Stage 0, autoresearch, or `./hub
  metrics`), present results as a Stage-0-style metric atlas canvas using
  [`.cursor/skills/metric-atlas-canvas/`](.cursor/skills/metric-atlas-canvas/) (gold
  template: `canvases/scgen-fig5-stage0-metrics.canvas.tsx` in the Cursor project).
  If the model uses encode→decode, the identity panel must jointly report **MSE,
  paired-cell Pearson²/gene, COD/gene, mean-vector Pearson², and per-cell Pearson r**
  (plus reconstruction MMD when available). Never call an AE good or bad from one
  of these axes alone; if a required value cannot be computed, state why. If a
  predefined DEG/marker set exists, also report its paired-cell Pearson²/gene and
  raw-vs-reconstructed mean-vector Pearson² beside the all-other-gene comparator;
  keep these identity values distinct from post-transport DEG scores.
- If you change behavior, **update the one canonical doc** that owns it (this file for
  rules, `conceptual_framework.md` for science, `hub_usage.md` for commands). Do not
  create new top-level docs or a new tracking/knowledge system.
- Don't hand-edit `docs/experiments/*` (auto-generated by `./hub vault`).
- Prefer archiving (`git mv` to a `_archive/` subfolder) over `rm` for tracked files.

## Current focus
See the latest `logs/research_logs/research_log_*.txt` for what's actively in flight
(this pointer never goes stale). As of **2026-07-27**: the bounded paper-scGen AE
follow-up is in `research_log_2026-07-27.txt`. Round 1 found dropout to be the
dominant distributional lever (MMD/JS/variance/zeros improve without it) while
paired-cell Pearson²/COD worsen; no variant passed the joint gate. Post-hoc, the
model/floor MMD ratio was flat (~1.8) across all four variants, so Round 1 improved
the **autoencoder, not the transport** — Round 2 (capacity) is skipped. **Round 3
(identity-first) is complete (job 35488948) with no eligible variant**: a per-gene
correlation loss had ~no effect on paired identity (likely because it is computed
on species/condition-mixed batches while the metric is within one slice), and the
variance loss improved distribution while collapsing COD. Guardrails proved
tighter than run-to-run noise (DEG R² spans 0.694–0.779 across paper-like runs),
so only identity-gate verdicts are interpretable at one seed. Also
verified: the decoded gap-closed fraction is noise-sensitive and cross-model
non-comparable on the LPS cut (denominator ~0.02–0.05 and model-dependent, vs
~0.22 on the atlas) — see `conceptual_framework.md` §5.9; the atlas north-star
policy is unchanged. **Track B + the composition-controlled breakdown (jobs
35538746, 35543634) are done.** Evaluating every group at matched n=180 shows the
apparent train→held-out collapse was mostly *composition* (mixed train slice vs
single held-out group). Controlled: LPS held-out paired Pearson² 0.100 ranks 6th
of 8 groups — **no paired-identity generalization deficit at all**; its COD
(−0.023) is the only negative one, so **pattern generalizes and amplitude does
not**. The atlas gap is real (seen ~0.48 → held out 0.32 human / 0.20 mouse).
Round 4 on LPS is retired. **E1/E2 (job 35547048) then showed the deficit is
within-group *variance collapse*** (reconstruction keeps ~2–4% of LPS within-group
variance, ~29–30% on atlas human and ~3–7% on atlas mouse — all medians over genes
that actually vary; see the 2026-07-30 correction in the log), and that a per-gene affine
correction fit on seen cells does **not** transfer to held-out cells, while an
oracle correction fit on them does (COD −0.02→+0.07 LPS, −0.10→+0.28 atlas human).
So the miscalibration is group-specific, not a global decoder bug. **E3 (jobs
35558027, 35560653) found the first intervention that helps**: a mean-preserving,
source-estimated per-gene variance de-attenuation applied post-hoc to saved
transport predictions leaves `r2_all`/marker R² *exactly* unchanged while moving
atlas model/floor 2.60→1.31 (m1) and 2.83→1.20 (m2), fgc 0.51→0.85 / 0.50→0.88.
It does **not** help on LPS in relative terms (1.79→1.93) and it worsens mean JS
on the atlas, so it is not yet a clean win. Score corrected predictions against
correspondingly corrected floor/ceiling — otherwise they fall below an
uncalibrated floor. Canvases: `scgen-fig5-stage0-metrics`,
`scgen-ae-followup-round1-metrics`, `scgen-ae-followup-round3-metrics`,
`ae-identity-cross-dataset-metrics`. Unbalanced OT remains paused.
