## The question

The overall question is never written down in one place. Read across the notebooks, it is this: can gene-level priors (orthologs, how strongly they correlate across species, or learned weights for them) let OT pair mouse and human cells of the same type? [I] Each notebook asks a narrower question:

- e14 has no header block, only a title (e14#c0) [D]. The commit messages describe the goal: the pairing accuracy of FGW "with correlated cross-species genes" (josh@a7ff6a0) [D].
- e15: "are top correlated orthologs shared across mice and humans?" The hypothesis is that at least 100 orthologs have a similar correlation structure in both species (josh@main:e15_gene_correlations.ipynb#c1) [D].
- e16: does FGW with optimized ortholog weights beat FGW with equal weights on a fixed ortholog set? The hypothesis is yes, because some orthologs are informative and others are "counterproductive" (e16#c1) [D].
- e17: can standard OT couple mouse and human cells "in untransformed ortholog space"? The hypothesis is that it works for non-immune "outlier" populations but not for immune cells, which "cluster by species before cell type" (e17#c1) [D].
- e19: does AGW beat FGW, "because orthologs correlate across species in non one-to-one ways"? (e19#c1) [D].

Earlier OT pairing without gene priors is covered in F01-F03. Conny's scGen/CellOT work on the CD8 holdout is covered in F06, and the mouse/human scale mismatch of the input files (see Setup) in F07.

## Setup

Short citation forms on this page: `e14#c23` means josh@main:e14_fused_gw.ipynb#c23 (and likewise for e15, e16, e17, e19, e20); `main#cN` means the main version of the notebook named in that section; `josh@<sha>:e16#cN` and `cellot#cN` mean the same notebook at that commit or on the `cellot` branch; `helpers :N` means josh@main:speciesot_helpers.py:N; `nb01.1` means conny:speciesOT/baseline/analysis/archive/01.1_hvg_investigation.ipynb and `nb05` means conny:speciesOT/baseline/analysis/archive/05_expanded_training_CD8_holdout.ipynb.

**Fused GW in plain words.** OT finds a coupling T: a table that says how much of each mouse cell's mass goes to each human cell. Rows and columns have fixed sums; here every cell has equal mass. Standard OT minimizes the sum of T_ij × M_ij, where M_ij is a distance between mouse cell i and human cell j, so it needs features that both species share. Gromov-Wasserstein (GW) needs no shared features. It compares the distances inside each species (C1 between mouse cells, C2 between human cells) and prefers couplings that send nearby mouse cells to nearby human cells. FGW mixes the two: objective = (1 - alpha) × OT term on M + alpha × GW term, plus epsilon × an entropy term that makes the plan smooth and fast to solve with Sinkhorn iterations. So alpha = 0 is plain entropic OT on M, and alpha = 1 is pure GW, which ignores M (helpers :1560-1563; POT `entropic_fused_gromov_wasserstein` at :1661) [C]. Both M and C1/C2 are divided by the median of their non-zero entries before solving (:1643-1657) [C].

**Ortholog cost (e14, e16).** BioMart one-to-one human-mouse orthologs are restricted to genes present in both data sets (:1448-1452) [C]. For each ortholog, the code computes the mean expression per cell type in each species and then r², the squared Pearson correlation between the mouse means and the human means (:1490-1496) [C]. Orthologs are ranked by r² (:1525) [C]. In the lung set there are only 7 shared types (e14#c14) [N], so each r² comes from 7 pairs of means; a gene that is high in a single type in both species gets r = 1 exactly, as the top four genes of the list do (Ms4a2, Il27, Fcer1a, Cpa3, e14#c14) [N][I]. M is the Euclidean distance between a mouse cell and a human cell on the top-K orthologs, using scaled expression (:1683-1807) [C]. C1 and C2 are squared Euclidean distances in each species' own 50-PC PCA (e14#c17; helper :1640) [C].

**Data, "old preprocessing" (e14; second half of e16).** Inputs are `data/tabula_muris/sampled_mouse_shared.h5ad` and `data/tabula_sapiens/sampled_human_shared.h5ad` in Josh's folder (1,562,533,262 and 6,098,345,094 bytes, both dated 2025-10-03; `ls` on FASRC) [R]. In AnnData files, `.X` is the main expression matrix and `.raw` an optional second copy. Here `.X` is not raw counts. Conny's notebook 01.1 printed it: the human values form a "staircase" of repeated non-integer values with maximum 8.51, and the mouse values reach exactly 10 in many places (nb01.1#c18-c22) [N]. Conny read this as log1p of counts normalized per cell (human), plus a per-gene scaling clipped at 10 (mouse), and found the raw integer counts in `.raw` (nb01.1#c22; conny:logs/research_logs/research_log_2026-04-20.txt:16-33) [D]. Each species contributes one donor, the one with the second-most cells (`top_n_organisms_from_species(dir, 2, ...)[1]`, e14#c4-c5) [C]. The code keeps 11 coarse immune types (`shared_cell_type`) and the lung (e14#c7-c9) [C]. `match_cells_by_celltype_tissue` (seed 0) then keeps the same number of cells per (cell type, tissue) in both species, in the same block order on both sides (helpers :455-568) [C]. Each species then gets `normalize_total`, seurat_v3 HVG selection (2000 genes) computed on a copy of the input `.X`, `log1p` and scaling (e14#c11-c12) [C]. So e14 normalizes and log-transforms values that were already transformed, and differently in the two species [C][I]. The result is 213 mouse and 213 human cells with 2000 genes each and 7 shared cell types (e14#c14, #c18) [N][C]. e14 computes a new 50-PC PCA for each species (e14#c17), but e16's old-preprocessing sections reuse the `X_pca` already stored in the input file (josh@8c39260:e16_learning_weights.ipynb#c51; main#c67) [C].

**Data, "new preprocessing" (main version of e15; first half of e16; e19).** The commit message calls it "raw.X and chromium only" (josh@0c806e0) [D]. It uses the `.raw` counts and keeps only 10x 3' v2 mouse cells (30,326) and 10x 3' v3 human cells (51,192) (e16#c6-c8) [C][N]. Cells from all donors are matched by cell-type and tissue ontology IDs, then normalized to 1e4 counts and log1p-transformed, with no scaling (e16#c11) [C]. The same loading code, run again in e20, prints 4,027 matched cells per species and 18,024 mouse genes (e20#c4-c5) [N]. Keeping one droplet platform per species is what Conny's hub later enforced as the `assay filter` (`conny:docs/concepts/assay filter.md`) [D]. e16 then keeps immune cells and draws 2000 of them (seed 42), using the same index for both species (e16#c28) [C].

**Data, e17.** e17 uses Conny's `cd8_holdout_v07.h5ad`: 12,836 cells × 1000 genes, 6,418 cells per species and 30 cell-type IDs; 390 cells are CD8 T cells (e17#c4, #c7) [N]. The file survives at fasrc:BK/cellot/cellot_gpu/datasets/speciesot-human-mouse/cd8_holdout_v07.h5ad (52,424,968 bytes, dated 2026-03-25 12:31) [R]. Conny's notebook 05 shows how the data were built: donors loaded with `n = -1` (which silently drops the smallest donor per species, see Problems), 14,451 BioMart orthologs, 1000 HVGs (scanpy flavor `seurat`) selected on both species together, then cell matching gives 6,418 cells per species, mouse block first and human block second in the same identity order (conny:speciesOT/baseline/analysis/archive/05_expanded_training_CD8_holdout.ipynb#c3-c13) [N][C]. It starts from `.X`, so its mouse half carries the extra per-gene scaling and its human half does not (nb05#c3, #c13; nb01.1#c18-c22) [C][N]. Notebook 05 writes `cd8_holdout.h5ad` at 12:27; the `_v07` file appeared four minutes later (`ls`) [R]. **Metric.** The metric is pairing (mapping) accuracy. For each mouse cell, take the human cell that receives the most mass in its row of T, then count how often the two cell-type labels agree (speciesot_simulation_helpers.py:287-300) [C]. e14 and e16 score coarse `shared_cell_type` labels; e17 scores the fine `cell_type` labels (e17#c14) [C]. Every number is a single run. No chance-level or majority-class baseline was computed in any notebook [C]; my estimates from saved outputs are in sections 2 and 6 [I].

### 5. e16, learned ortholog weights (2026-04-08 -> 2026-04-29)

`alternating_weighted_fgw_opt` ("AltOpt", e16#c4) alternates two steps [C]. Step one solves FGW with the cost M(w) = Σ_k w_k (mouse_ik - human_jk)². Step two updates the weights w on the simplex (w ≥ 0, Σw = 1) by minimizing the transport-weighted mismatch plus an L2 penalty [C]. It starts from random Dirichlet weights with `random_state=None`, so runs are unseeded, and it runs at most 25 outer iterations [C]. The main-branch runs also cut the inner FGW solve to one iteration per outer step (`fgw_inner_iter=1`, main#c34, #c68) [C]. None of the saved logs shows convergence [N]. ## Verdict

- The strongest result is narrow. On one donor pair's lung immune cells, plain entropic OT on about 100 orthologs ranked by cross-species cell-type correlation pairs 90.1% of mouse cells with a human cell of the same coarse type (e14#c22-c23, #c35) [N]. The result is deterministic and was reproduced exactly in a second session [N]. A trivial "commonest type" guess probably scores at least 53.5% on the same cells (section 2) [I]. The labels being scored were also used to rank the genes and to balance the two cell sets. So the number measures how well label-chosen marker genes transfer between species. It does not test unsupervised cell pairing [I].
- The "partly worked" status rests on e14 alone. It shows that one-to-one orthologs carry a shared cell-type signal that OT can use in a small, supervised setting. Nothing here shows that gene priors help when labels are not available [I].
- The GW term's effect depends on the settings. In the lung set it did not help at K = 50 or 100, but alpha = 0.25 helped at K = 10-20; in the all-tissue run it raised the best accuracy at epsilon 0.01 from 76.3% to 79.9% (josh@a7ff6a0:e14_fused_gw.ipynb#c25) [N]. Pure GW was weak in e14 (45-47% in the lung, below the trivial guess) and failed badly across all tissues (5-7%) [N][I]. In e16 it reached 73.7% on the same 213 lung cells, at epsilon 1 and with the PCA stored in the input file (josh@8c39260:e16_learning_weights.ipynb#c35) [N]. This was never studied systematically [I].
- e15 shows that some correlation structure is shared: 18.5% of strong human pairs are also strong in mouse (#c50) [N]. Only 490 of the 1,133,265 human pairs (0.04%) pass r² > 0.5 (#c23, #c50; 1,506 × 1,505 / 2 = 1,133,265) [N][I]. If mouse pairs pass at a similar rate, 18.5% is far above what unrelated pairs would give [I]. But r² is computed across cells of many types, so the shared pairs are mostly cell-type marker programs (#c52) [N]. A null model (for example, shuffled ortholog pairs) was never run, and the hypothesis of "≥ 100 orthologs" was never tested as stated, so e15 is inconclusive [I].
- e16 did not work. Learned weights never beat the best plain top-K list, and the optimizer neither converges nor uses a seed [N][C].
- e17 shows that OT, GW and EMD in Conny's shared 1000-gene PCA space reach only 18-25% on fine labels, above chance (about 6.4%) but far below e14 [N][I]. Its data mix two scalings (an extra per-gene scaling on the mouse side only) and two sequencing platforms (see Setup) [N][D]. Its cells, labels and gene space all differ from e14. So the negative result is weak, and e14's 90% against e17's 25% says nothing about the value of the ortholog prior on its own [I].
- e19 has no result.
- Overall the evidence is weak. All numbers are single runs; the headline uses one donor per species and 213 cells; AltOpt and e17's cell draw are unseeded; no data were held out; and e14, the April e15 and e17 start from `.X` values that had already been transformed, differently in each species [I].

## Problems in how it was done

- **Labels leak into the method.** Ortholog ranking uses per-cell-type means computed from the same labels on the same cells that are scored (helpers :1302-1525; e14#c13; in e16 the ranking uses all matched cells, e16#c22) [C]. In addition, the cell sets are balanced per label before OT (helpers :514-515) [C]. With 7 types, genes that mark a single type get r = 1, so the ranking simply picks marker genes (e14#c14) [N][I]. This makes 90.1% an optimistic, transductive number (fit and scored on the same cells). For a new species or treatment, labels would not be available [I].
- **Inputs were already transformed, differently in each species.** `.X` in Josh's atlas files is not counts: it is log-normalized on the human side and, in addition, per-gene scaled and clipped at 10 on the mouse side (values printed in nb01.1#c18-c22 [N]; Conny's reading of them, research_log_2026-04-20.txt:16-21 [D]). e14 and the old-preprocessing parts of e16 normalize, log-transform and scale it again, and run seurat_v3 HVG selection, a method meant for raw counts, on it (e14#c11-c12) [C]. The April e15 computes correlations on it, and Conny's v07 data for e17 carry the mismatch into a joint PCA of both species [C]. The mismatch was found on 2026-04-20 and is covered in F07. Josh's switch to `.raw` (josh@0c806e0) [D] fixed it for the later runs only. e14's 90.1% was never re-run on `.raw` data [C].
- **Settings chosen on the test set.** The reported number is the maximum of a 60-point grid (e14#c22) [N]. The lung was chosen after the all-tissue run looked harder (josh@a7ff6a0 -> josh@6764415) [G][D]. No donor or tissue was held out, so the headline is biased upward [I].
- **Single runs, small n, no baselines.** e14 uses one donor pair and 213 cells, so 1 cell = 0.47 points [N][I]. No notebook computes chance or majority-class accuracy [C]. The constant 53.5% (e14#c22) is probably a failed solve that also reveals a trivial baseline of at least 53.5% [I]. Without a baseline, differences of a few points cannot be judged.
- **Outputs from different sessions or states sit side by side.** In e14 main, c20-c27 come from 2026-02-25, while c1-c19 and c35 come from the session committed on 2026-04-24 [N]. ## Terms used here

- **coupling / plan T**: table of how much mass each mouse cell sends to each human cell.
- **GW (Gromov-Wasserstein)**: OT that matches distances inside each species instead of comparing features across species.
- **FGW, alpha, epsilon**: fused GW. `alpha` weights the GW term (0 = plain OT on M, 1 = pure GW). `epsilon` is the entropy weight; larger means a smoother plan (helpers :1560-1563).
- **K / `orths`**: number of top-ranked orthologs used to build the cross-species cost M.
- **correlated orthologs**: one-to-one orthologs ranked by r² between mouse and human per-cell-type mean expression (helpers :1302).
- **`shared_cell_type`**: coarse cross-species label from Josh's mapping table, e.g. "T cell", "HPSC" (josh@main:tabula_make_samples.ipynb#c22).
- **matched cells**: output of `match_cells_by_celltype_tissue`, which keeps an equal number of cells per (type, tissue) in both species.
- **pairing (mapping) accuracy**: share of mouse cells whose highest-mass human partner has the same label.
- **old / new preprocessing**: `.X`, one donor, HVG + log1p + scaling on already-transformed values (old) versus `.raw` counts, 10x only, all donors, normalize + log1p (new; "raw.X and chromium only").
- **`.X` / `.raw`**: the main and the backup expression matrix of an AnnData file; in Josh's atlas files `.X` is transformed and `.raw` holds the counts.
- **`_v07`**: suffix of Conny's dataset copies saved for anndata 0.7, the version in the CellOT environment.
- **AltOpt**: e16's alternating optimization of the FGW plan and the ortholog weights.
- **EMD**: exact, unregularized OT (`ot.emd`).
- **AGW / COOT**: augmented GW, which mixes GW with co-optimal transport; COOT also couples genes to genes.
- **K = max**: all 13,960 ranked orthologs (e16#c42).
