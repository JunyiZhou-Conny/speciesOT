# F06 · speciesot_v1: mouse-to-human translation with T-cell holdouts (scGen vs IMPACT-OR vs cell-type CellOT)

> The question was whether a mouse-to-human map, learned on most cell types of a matched Tabula Muris / Tabula Sapiens dataset, can predict human cells of a type it never saw. Conny trained the CellOT code's autoencoder and CellOT transport maps and compared three predictors: a latent mean shift ("scGen"), CellOT with species as the condition ("IMPACT-OR"), and CellOT with cell type as the condition ("cell-type CellOT"). On the CD8 T-cell holdout, IMPACT-OR's predicted mean expression matched real human CD8 cells best (r² 0.72, against 0.65 and 0.55), and IMPACT-OR beat cell-type CellOT on this metric in all four holdout groups. All of this rests on mis-normalised data, a gene list chosen with the held-out cells included, one training seed, no "do-nothing" baseline and three different metric definitions; the "improvement" seen between notebooks 06 and 08 was an artifact of metric definitions (mainly a Pearson r stored under the name `r2`). Status: inconclusive; the runs were superseded by F07 (re-normalised data) and F08 (HVG flavours).

## The question

Can an optimal-transport map from mouse cells to human cells, trained without one cell type, predict how that cell type looks in human? The 03-30 log states the goal as "Transport gene expression across species (mouse → human) using optimal transport, with held-out CD8+ T cells as OOD evaluation" [D conny:logs/research_logs/research_log_2026-03-30.txt:5-6]. OOD ("out of distribution") here means a cell type that was absent from training.

The notes for the 2026-03-24 meeting ask for a CellOT-paper-style MMD bar plot of three models ("Scgen, Cellot, Cellot swapped") and scGen-paper-style r² scatter plots [D research_log_2026-03-22.txt:42-51]; who asked is not written down. The next steps from the 2026-03-25 meeting add full-context UMAPs, removal of thymocytes, an in-distribution (IID) baseline, more cells, a brute-force search over holdouts, and non-atlas batch-effect data [D research_log_2026-03-22.txt:54-69]; the 03-30 log repeats them with comments and adds an outlier check, faceted UMAPs, an MMD sample-size check and a non-classical-monocyte holdout [D research_log_2026-03-30.txt:154-210]. In this family only the UMAPs (06.1–06.4), the outlier check (06.5), a partial thymocyte removal (Group B) and the extra T-cell holdouts (Groups B–D) were done; the IID runs and the monocyte holdouts are F07 (toggle_ood); no non-atlas data were used [I from the notebooks listed below].

The "autoresearch" loop designed in the same log [D research_log_2026-03-30.txt:213-233] does exist: `autospeciesOT/` (README.md, program.md, run_experiment.py, results.tsv) sat in the FASRC working tree by early April (nb08 wrote its results.tsv there on 2026-04-08/09 [N josh@cellot:baseline/analysis/08_cross_experiment_evaluation.ipynb#c15]) and was tracked in Conny's repo from 2026-05-15 until it was deleted on 2026-05-25 [G conny@c342331, conny@4200f8e; the same commits are in the history of Josh's `junyi` branch]. Its priority list (CD8; CD8 plus thymocyte exclusion; CD4 + CD8 + thymocyte; CD4; then monocytes/macrophages), with the species framing first and the cell-type framing second, matches Groups A–D; the monocyte item was not run in this family [D conny@c342331:autospeciesOT/program.md]. Its results.tsv holds only the 8 rows that nb08 exported, no agent runs [R conny@c342331:autospeciesOT/results.tsv], so the groups were run by hand and the loop itself never ran [I].

## Setup

**Cells.** Josh's pre-sampled files `sampled_human_shared.h5ad` and `sampled_mouse_shared.h5ad` (Tabula Sapiens / Tabula Muris, sampled to at most 1,000 cells per cell type [C josh@cellot:tabula_make_samples.ipynb#c3; D josh@d074030 commit message]) were loaded donor by donor. The loader of that time sliced the donor list with `[:n]` and was called with `n=-1`, which drops the smallest donor of each species (human TSP13, 79 cells; mouse 3-M-8/9, 5 cells) [C josh@ddc56ad:speciesot_helpers.py:34-44; D research_log_2026-04-13.txt:338-372; the fix is josh@cellot:speciesot_helpers.py:34-55]. So every dataset here starts from 23 human and 39 mouse donors: 58,852 + 47,802 = 106,654 cells [N josh@953e669:prediction/Human_Mouse_Data.ipynb#c5, #c7; N josh@cellot:baseline/analysis/05_expanded_training_CD8_holdout.ipynb#c3].

**Genes.** One-to-one orthologs (gene pairs that descend from one ancestral gene, with exactly one copy in each species) from Ensembl BioMart: 14,451 genes [N 05_expanded_training_CD8_holdout.ipynb#c5; josh@ddc56ad:baseline/analysis/01_data_preprocessing.ipynb#c27]. Iteration 1 used mygene symbol matching instead, according to the log [D research_log_2026-03-30.txt:24]; a code comment records 14,633 shared genes for that approach [D josh@ddc56ad:baseline/analysis/01_data_preprocessing.ipynb#c25].

**Values.** The `.X` matrices were used as shipped. Human values span 0–8.97 and mouse values 0–10.00 [N josh@ddc56ad:baseline/analysis/01_data_preprocessing.ipynb#c14, #c15]. The 04-20 audit found that mouse `.X` carried an extra per-gene scaling clipped at 10, so "every cross-species analysis run to date has been operating on MISMATCHED scales" [D research_log_2026-04-20.txt:15-20]. This is the "stale" preprocessing; F07 covers the fix.

**Matching.** For each (cell-type ID, tissue ID) pair present in both species, `match_cells_by_celltype_tissue` keeps min(n_mouse, n_human) random cells (seed 0) [C josh@ddc56ad:speciesot_helpers.py:454-514]. Result: 6,418 cells per species in 30 Cell Ontology (CL) types [N 05_expanded_training_CD8_holdout.ipynb#c9, #c11]. The 195 mouse CD8 cells come mostly from spleen (138), lung (31), subcutaneous fat (19) and liver (7), from 24 donors [N josh@cellot:baseline/analysis/06.5_outlier_cell_investigation.ipynb#c5]; the human CD8 cells have the same tissue counts because matching is per (type, tissue) [I].

**HVGs** (highly variable genes: the 1,000 genes whose expression varies most across cells): scanpy `highly_variable_genes(flavor='seurat', n_top_genes=1000)`, run on mouse and human cells stacked together, with no species batch key. In the earliest committed nb01 (a re-run of 2026-03-24) they were chosen on matched training cells only [C josh@ddc56ad:baseline/analysis/01_data_preprocessing.ipynb#c30]; the code that built iteration 1's file on 2026-03-18 is not preserved. Groups A–D chose them on all 106,654 cells, held-out cells included [C 05_expanded_training_CD8_holdout.ipynb#c7; 07_data_prep_all_holdouts.ipynb#c5]. None of 16 standard immune markers (PTPRC, CD3D/E/G, CD4, CD8A/B, CCR7, GZMB, …) is among these 1,000 genes [N josh@cellot:baseline/analysis/12_figure_g_replication.ipynb#c6].

**Splits and holdout groups.** Iteration 1 used CellOT's `toggle_ood` split: the held-out cells are split 50/50 into `ood` (evaluated) and `ignore` (discarded). All later runs use the `train_test` split with a holdout dictionary: every cell with a held-out label goes to `ood`, and the rest is split 80/20 into train/test per condition [C conny@c342331:cellot/cellot_gpu/cellot/data/cell.py:261-281 (train_test), 322-353 (toggle_ood)].

**Models.**
- *Autoencoder (AE).* The CellOT code's `scgen` model: an MLP encoder and decoder with a 50-number latent code (the "latent space"); loss = MSE + β‖z‖² with β = 0, so a plain autoencoder, not a variational one [C conny:cellot/cellot_gpu/configs/models/scgen.yaml; run configs]. Iteration 1: hidden layers [512, 512], dropout 0, 5,000 steps, batch 128 [C fasrc:BK/cellot/cellot_gpu/results/speciesot_cpu/speciesot_scgen/config.yaml]. Groups A–D: hidden [256, 256], dropout 0.1, 50,000 steps, batch 256, learning rate 1e-3 [C fasrc:BK/cellot/cellot_gpu/results/speciesot_cd8/speciesot_scgen/config.yaml]. The saved `model.pt` is the step with the lowest MSE on one test batch [C conny:cellot/cellot_gpu/cellot/train/train.py:233-240].
- *IMPACT-OR* (later renamed IMPACT_CellOT). CellOT's ICNN (input-convex neural network) transport map, trained in the AE's latent space with condition = species: source mouse, target human, one cell type held out [C fasrc:BK/cellot/cellot_gpu/results/speciesot_cd8/impact_or/config.yaml]. ICNN 4 × 64 units, Adam lr 1e-4 (β 0.5, 0.9), batch 128, 10 inner steps, 10,000 steps (iteration 1) or 50,000 (A–D) [C run configs]. What "IMPACT-OR" stands for was not found; the later concept doc lists it as a TODO [D conny:docs/conceptual_framework.md:80].
- *Cell-type CellOT* (folders `cellot/`, `speciesot_cellot_swapped/`). Same ICNN and AE; condition = cell-type status (source `non_cd8`, target `cd8`); holdout = all human cells [C fasrc:BK/cellot/cellot_gpu/results/speciesot_cd8/cellot/config.yaml]. It learns non-CD8 → CD8 on mouse cells only, and is tested by pushing all 6,223 human non-CD8 cells and comparing them with the 195 human CD8 cells [C; N 06_cd8_holdout_evaluation.ipynb#c20]. Its task file calls this "Analogous to CellOT paper's cross-species LPS experiment" [C conny:cellot/cellot_gpu/configs/tasks/_archive/speciesot_v1/speciesot-cd8-swapped-cellot.yaml:1-4]. The two CellOT configs differ only in data file, source/target and holdout [C diff of the two config.yaml files in fasrc:BK/cellot/cellot_gpu/results/speciesot_cd8/].
- *scGen* (latent mean shift). Computed inside nb06, not by the CellOT code: δ = mean latent code of the 6,223 human non-CD8 matched cells minus that of the 6,223 mouse ones; prediction = decode(encode(mouse CD8) + δ); no cell-type balancing [C 06_cd8_holdout_evaluation.ipynb#c17, #c18]. ‖δ‖ = 4.11 [N #c17]. It was never run through evaluate.py and was not computed for Groups B–D [N 08_cross_experiment_evaluation.ipynb#c7; R: no scGen evals folder in any run folder].
- *CellOT checkpoints.* `model.pt` is the step with the lowest MMD between one 128-cell test batch and its transport, in latent space, gammas [2, 1, 0.5, 0.1, 0.01, 0.005] [C conny:cellot/cellot_gpu/cellot/train/train.py:57-85, 152-158; conny:cellot/cellot_gpu/cellot/losses/mmd.py:114-125].
- *Which code actually ran.* The Slurm tracebacks show `scripts/train.py` and `scripts/evaluate.py` from `cellot/cellot_gpu/`, but the `cellot` package itself imported from `speciesOT/cellot/cellot/` (the editable install in the `CellOT` env) [R fasrc:BK/cellot/cellot_gpu/results/speciesot_cd4/speciesot_scgen/train_3665630.err; speciesot_cd8_nothymo/speciesot_cellot/eval_ds_3682479.err]. That package copy is in no repo and not in the backup (fasrc:BK/cellot/ holds only `cellot_gpu` and `sbatch`). Its traceback line numbers match the vendored copy cited on this page for `data/cell.py` but are 1–11 lines off for `train/train.py`, `utils/loaders.py` and `utils/evaluate.py` [R vs C conny@c342331], so the cited package code is the closest surviving version, not the exact one [I]. The cited `scripts/evaluate.py` lines do match the 2026-04-05 tracebacks [R, C].

**Evaluation.** All reported numbers are in "data space": predictions decoded back to the 1,000 genes and compared with the raw human cells of the held-out type [C; N imputed shape (195, 1000) in 06_cd8_holdout_evaluation.ipynb#c6]. (Iteration 1 also wrote a latent-space evaluation; it is empty [R].) Three metric pipelines were used:

| Pipeline | Cells used | "r² of means" | MMD (maximum mean discrepancy: a kernel distance between two sets of cells) | kNN enrichment |
|---|---|---|---|---|
| CellOT `scripts/evaluate.py` → `evals.csv` | 100 random cells per side, 10 repeats, no seed; larger n only if both sides have enough cells | Pearson r of the two gene-mean vectors, **not squared**, named `r2-means` | biased estimate, gammas `logspace(1,-3,50)` | predicted cells only: share of their 50 nearest neighbours that are predicted (0.5 = mixed, 1 = separate) |
| nb06 `compute_ood_metrics` | all cells | r squared | biased, gammas `logspace(-3,3,50)` | averaged over predicted *and* real cells |
| nb08 "full-cell" | all cells | r squared | biased, gammas `logspace(1,-3,50)` | averaged over both |

Sources: conny@c342331:cellot/cellot_gpu/scripts/evaluate.py:61, 70, 75-84, 175-181; conny@c342331:cellot/cellot_gpu/cellot/utils/evaluate.py:16-47; 06_cd8_holdout_evaluation.ipynb#c9; 08_cross_experiment_evaluation.ipynb#c3 [C]. evaluate.py first skipped MMD at exactly 1,000 features and was patched to `<= 1000` [D research_log_2026-04-08.txt:267-269], some time between 2026-03-25 (evals.csv without MMD or enrichment rows) and 2026-04-06 (with them) [R conny:speciesOT/baseline/results/speciesot_cd8/impact_or/evals_ood_data_space/evals.csv vs fasrc:BK/cellot/cellot_gpu/results/speciesot_cd8/impact_or/evals_ood_data_space/evals.csv].

**Differences from the CellOT paper.** The paper trains 250k iterations with batch 256 [P CellOT, Methods "Training and technical details", "Hyperparameters"]; F06 used 10k (iteration 1) or 50k ICNN steps and batch 128 [C]. The paper reports MMD on the top-50 marker genes and notes that MMD "is biased with increasing dimensionality" [P CellOT, Methods "Feature selection"]; F06 used all 1,000 genes [C]. The paper reports "an unbiased estimate of MMD" [P CellOT, Methods "maximum mean discrepancy"]; the code computes the biased one [C conny:cellot/cellot_gpu/cellot/losses/mmd.py:5-10]. The paper computes the 1,000 HVGs "based on the training set only" [P CellOT, Methods "Single-cell RNA sequencing data"]; Groups A–D did not [C]. In Groups A–D the AE was smaller than the CellOT code's default ([256, 256] vs [512, 512]) [C conny:cellot/cellot_gpu/configs/models/scgen.yaml]. Seeds: `random_state 0` everywhere and one training run per configuration [C].

## Verdict
- Supported: in Group A, with this preprocessing and one seed, IMPACT-OR's predicted gene means were closer to real human CD8 means than those of cell-type CellOT and of the latent mean shift: squared Pearson r 0.718 vs 0.649 vs 0.550 on all genes and 0.64 vs 0.56 vs 0.44 on the 100 most variable genes; L2 distance of means 0.695 vs 0.763 vs 1.008 [N 06…#c22, #c23]. IMPACT-OR also beat cell-type CellOT on r² in all four groups [R], although the two push different source cells.
- Supported: decoded predictions are much less variable than real cells (SD more than 10× smaller for 9 of 16 CD8-distinctive genes; r² of SDs ≤ 0.34; gene–gene correlation r ≈ 0.02) [R, N]. The models reproduce averages, not cell-level distributions.
- Not known: how much better than "doing nothing". No identity baseline (mouse cells unchanged) and no autoencoder-only reference (human CD8 encoded and decoded) were computed in this family. The only later tables that use these runs, nb08.1's stale-vs-renorm export and the generated model cards, contain no baseline either [R conny@c342331:autospeciesOT/results_renorm_vs_stale.tsv; D fasrc:BK/docs/model_cards/*speciesot*; searched all speciesot run folders and all CSV/JSON/TSV files in the local mirror of the FASRC backup; I].
- Weak: "scGen has the best MMD". Against IMPACT-OR (both 195 vs 195 cells) scGen's MMD was lower, 0.0187 vs 0.0524, but only on nb06's own gamma grid `logspace(-3,3)`; scGen was never scored with evaluate.py's grid, and against cell-type CellOT the sample sizes differ [N 06…#c23; C].
- Not supported: "scGen and IMPACT-OR predictions mix well with real cells". The CellOT definition on the same IMPACT-OR predictions gives 0.99, i.e. separated [R]; for scGen only the averaged notebook version exists. Also not supported: any ranking of groups by MMD (different n) or by r² differences near 0.01 (run-to-run noise); the nb06 → nb08 "gain".
- Strength of evidence: low. The planned runs completed, but every number is confounded by the data problems listed below. This is why the status is "inconclusive" rather than "partly worked": the question on the page (does a mouse → human map transfer to an unseen cell type?) cannot be answered from these numbers without a do-nothing reference [I].

## Problems in how it was done
- **Mismatched preprocessing.** Mouse values were scaled per gene and clipped at 10, human values were not [D research_log_2026-04-20.txt:15-20; N josh@ddc56ad:baseline/analysis/01_data_preprocessing.ipynb#c14-15]. The learned "species effect" includes this artifact, and every number here inherits it.
- **HVGs chosen with the held-out cells** in Groups A–D [C 05…#c7; 07…#c5], later named leakage [D meeting_notes_2026-04-30.md:15]; the CellOT paper computes them on the training set only [P CellOT, Methods "Single-cell RNA sequencing data"]. They were also computed on mouse and human cells stacked without a species batch key, which, according to the 04-20 log, flags genes that merely differ between species [D research_log_2026-04-20.txt:285-291]. The resulting gene list contains none of 16 immune markers [N 12…#c6], so CD8 identity is barely represented.
- **"Strict OOD" only by exact label.** Generic "T cell" cells (CL:0000084) stay in training in all groups [C 07…#c8]. The AE pool is the whole atlas sample minus exact labels, and Josh's shared-type map lists human "activated CD8-positive" and "naive thymus-derived CD8-positive" T cells [C josh@cellot:tabula_make_samples.ipynb#c22]; whether such cells reached the AE training data was not checked.
- **Iteration 1 evaluation.** The truth set included `ignore` cells, r was reported as r², evals.csv was empty, and the holdout was narrower than the log says [C 04…#c9; R; D vs C]. nb04 also reads `hvg-top1k.h5ad`, which was rewritten on 2026-03-24, six days after the model was trained on an earlier version. If nb04's saved outputs come from a run after the rewrite (it was committed that day) and the gene lists differ, nb04 silently falls back to matching genes by position [R ssh listing; G josh@ddc56ad; C 04…#c9; I]. When nb04 last ran is not recorded.
- **Package code not preserved.** The jobs imported the `cellot` package from a copy that is in no repo and not in the backup (see Setup), so the exact training and evaluation code cannot be re-read [R tracebacks; I].
- **Three metric definitions.** evaluate.py's `r2-means` is r [C evaluate.py:70]; nb04 and the first nb08 print r as "r²"; nb06 and the final nb08 square it; the model cards report the mean over repeats of r² (0.6853 IMPACT-OR, 0.6241 cell-type CellOT, vs nb08's 0.6239, which squares the mean r) [D fasrc:BK/docs/model_cards/gpu__speciesot_cd8__impact_or.md, gpu__speciesot_cd8__cellot.md; R recomputed from evals.csv]; 06.1 teaches 1 − SS_res/SS_tot [N]. Numbers from different notebooks are not comparable without checking which definition was used.
- **MMD not comparable.** nb06 used gammas `logspace(-3,3)`, the others `logspace(1,-3)` [C]. The biased estimator depends on n; when most gammas are large it tends to about 1/n₁ + 1/n₂ (0.0103 for 195 vs 195, 0.0053 for 195 vs 6,223) [I]. Groups were scored at n = 100, 500 and 80 [R]. No MMD floor was computed; floor helpers came later [G conny@8a9a103].
- **Enrichment misread.** The notebooks average over predicted and real cells; CellOT's version scores predicted cells only. Same IMPACT-OR predictions: 0.513 (nb06) vs 0.992 (evaluate.py) [N, R]. Under random mixing the notebook version gives about 0.50 for 195 vs 195 and about 0.94 for 6,223 vs 195 [I], so cell-type CellOT's 0.970 is mostly the size imbalance. A notebook value near 0.5 is also what one tight cluster of predictions gives when real cells lie next to it: predicted cells then score near 1 and real cells near 0, and the narrow predicted spread seen in nb12 fits this picture [I]. So nb06's 0.51 for IMPACT-OR and scGen does not show mixing.
- **Unequal comparisons.** Cell-type CellOT pushes 6,223 human non-CD8 cells of 29 types [N 06…#c20]; scGen was scored in a notebook only, and is absent from nb08 [C, N].
- **No baselines.** No identity baseline, no AE round-trip reference, no MMD floor [searched; I].
- **One seed, noisy evaluation.** One training run per configuration [C]. evaluate.py subsamples without a seed; the two evaluations of the same Group A models gave mean r 0.8248 vs 0.8278 (IMPACT-OR) and 0.7838 vs 0.7899 (cell-type CellOT) [R conny:speciesOT/baseline/results/speciesot_cd8/*/evals_ood_data_space/evals.csv vs `fasrc:BK/cellot/cellot_gpu/results/speciesot_cd8/{impact_or,cellot}/evals_ood_data_space/evals.csv`], with per-repeat SDs of r of 0.009–0.023 [R]. Differences near 0.01 in r² are inside this noise.
- **Checkpoints chosen on one test batch** (128 cells for CellOT, 256 for the AE) of in-distribution cells [C train.py:57-85, 152-158, 233-240].

## Terms used here
- `speciesot_v1` — the inventory's phase label for this family: `_iter1`, `_iter2_groupA`, `_groupB/C/D` [C conny:scripts/build_experiments_inventory.py:333-451].
- Iteration 1 / iteration 2 — the 2026-03-18 "T cell" run and the 2026-03-25 CD8 run [D research_log_2026-03-30.txt].
- Group A/B/C/D — here: CD8 / CD8 with thymocytes removed from the AE / CD4 + CD8 + thymocyte / CD4. In the HVG matrix (F08) group b means CD8 + thymocyte held out [C 18…#c5 `HOLDOUT_LUT`]; renorm (F07) has its own `cd8_thymo`.
- IMPACT-OR — CellOT with species as the condition (mouse → human) and one cell type held out; later IMPACT_CellOT; folders `impact_or/`, `speciesot_cellot/`.
- Cell-type CellOT — CellOT with `cd8`/`non_cd8` as the condition and human cells held out; folders `cellot/`, `speciesot_cellot_swapped/`; called "Normal CellOT" in renorm.
- swapped — suffix of the cell-type-status data files in nb05/nb07; its meaning flipped later (see Problems).
- scGen (in this family) — the CellOT autoencoder plus a mean shift computed in nb06.
- `v07` — h5ad copy meant to be readable by anndata 0.7 in the CellOT environment [D 07…#c13; D research_log_2026-04-20.txt:569-590].
- `model-scgen` — symlink in each run folder that evaluate.py follows to find the AE [C conny@c342331:cellot/cellot_gpu/scripts/evaluate.py:116; cellot/utils/evaluate.py:281].
- `autospeciesOT` — the planned autonomous experiment loop of the 03-30 log (program.md, run_experiment.py, results.tsv); never run, deleted 2026-05-25 [D, G conny@c342331, conny@4200f8e].
- `ood` / `ignore` — CellOT split labels: evaluated cells / discarded cells (`ignore` exists only in toggle_ood).
- `evals_ood_data_space` — evaluate.py output folder; "data space" = predictions decoded to genes.
- `r2-means` — Pearson r (not r²) of gene means in evals.csv.
- full-cell vs subsample — nb08's two ways to score: all cells, or 100-cell draws repeated 10 times.
- stale — the original, mismatched preprocessing (F07).
- "top 100 DEGs" (nb06) — the 100 most variable genes of the real human CD8 cells.

## What the package needs from this
The package's `R2Evaluation` correlates prediction and truth gene by gene across paired rows, then squares and averages [C conny:src/speciesot/speciesot_core.py:115-128]. That is a different metric: F06 compares the gene-mean vectors of two unpaired cell sets. To reproduce any F06 number the package needs "squared Pearson r between gene-mean vectors" (and r, if it wants to match evals.csv).

**Candidate 1 — metric test on saved predictions (recommended).**
- Inputs: truth = cells with `condition == human` and `cell_type_ontology_term_id == CL:0000625` in fasrc:BK/cellot/cellot_gpu/datasets/speciesot-human-mouse/cd8_holdout_v07.h5ad (git-LFS pointer in conny and josh: sha256 f136255c…, 52,424,968 bytes) [R, G]; predictions = fasrc:BK/cellot/cellot_gpu/results/speciesot_cd8/impact_or/evals_ood_data_space/imputed.h5ad (195 × 1,000; a copy of the same size is in mac:OptimalTransport/speciesOT/baseline/results/speciesot_cd8/impact_or/evals_ood_data_space/) and …/cellot/evals_ood_data_space/imputed.h5ad (6,223 × 1,000) [R]. FASRC is not needed: the git-LFS objects of the 2026-03-25 files that nb06 read are in Conny's repo at `conny:speciesOT/baseline/results/speciesot_cd8/{datasets/cd8_holdout_v07.h5ad,impact_or/evals_ood_data_space/imputed.h5ad,cellot/evals_ood_data_space/imputed.h5ad}` (52,424,968 / 866,233 / 25,528,823 bytes, the same sizes as on FASRC) [G josh@1db1592; R ssh listing].
- Expected, all cells: r² of means 0.7178 (IMPACT-OR) and 0.6488 (cell-type CellOT); r² of SDs 0.3227 / 0.2814; L2 of means 0.6954 / 0.7626; MMD with gammas `logspace(1,-3,50)` 0.0725 / 0.1013, or with nb06's `logspace(-3,3,50)` 0.0524 / 0.0694 (biased estimator, all 1,000 genes) [N 06…#c23; 08…#c17, #c19].
- Tolerance: deterministic; nb06 and nb08 agree to four decimals on files written on different days, so ±1e-3 [N; I].
- Optional subsample protocol (100 cells × 10, unseeded): mean r 0.825–0.828 for IMPACT-OR over two evaluations; tolerance ±0.01 [R].

**Candidate 2 — latent-mean-shift baseline with the frozen AE.**
- Inputs: the same h5ad; the AE checkpoint josh@cellot:baseline/results/speciesot_cd8/speciesot_scgen/cache/model.pt (LFS, 8,059,574 bytes; copies in fasrc:BK/cellot/cellot_gpu/results/speciesot_cd8/speciesot_scgen/cache/ and mac:OptimalTransport/speciesOT/baseline/results/speciesot_cd8/speciesot_scgen/cache/) and its config.yaml (MLP 1,000 → 256 → 256 → 50, dropout 0.1, used in eval mode) [R, C].
