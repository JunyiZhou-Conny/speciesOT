# F15 · Repairing the paper-scGen autoencoder: Rounds 1–3, composition and variance checks, and the de-attenuation ("devar") test

> Stage 0 ([F12](F12-scgen-fig5-stage0-and-stage1.md)) showed that the original scGen variational autoencoder (VAE) predicts the mean LPS response well but reconstructs single cells poorly. From 2026-07-23 to 07-30 Conny and an AI agent ran a small pre-registered study to repair that autoencoder without losing the mean result. Two training rounds (Round 1: KL term and dropout; Round 3: extra correlation and variance loss terms) produced no model that passed the study's own pass rules, and Round 2 (more latent capacity) was skipped. Inference-only checks then showed that most of the apparent identity loss on held-out rat cells was a composition effect, that the decoder keeps only about 4% of within-group variance on LPS (3–30% on the atlas), and that inflating the spread of saved predictions while keeping every gene mean ("devar") lowers MMD at no cost to mean R²; a pre-registered control then showed that the same factors with shuffled gene labels, or one global factor, give almost the same gain. Status: did not work; the line was closed on 2026-07-29, so the `AGENTS.md` sentence "E3 found the first intervention that helps" is out of date.

## The question

- Starting point (F12): the frozen paper checkpoint reproduces Fig. 5 (all-gene R² 0.9067, top-100 DEG R² 0.7423) (RS/stage0/metrics.json) [R]. Its reconstruction of the held-out rat LPS6 cells is weak: per-gene paired Pearson² 0.0862, COD −0.0199, decoded MMD fraction −2.96 (RS/stage0/recon_identity_extended.json; metrics.json) [R]. The audit called the model "a mean-preserving denoiser but a weak paired-cell identity map" (L23:15-16) [D].
- Proposal (07-23): "a bounded AE repair study is warranted before adding an unbalanced-OT degree of freedom" (L23:18-19); "Do not restart open-ended HPO"; a candidate "must improve cell/cloud identity without losing the replicated mean-program result" (L23:112-122) [D]. HPO = hyperparameter search.
- Spec question (S1:2-4): "Can cell-specific and distributional reconstruction improve while preserving scGen Figure-5 all-gene and top-100-DEG perturbation prediction?" [C]
- Later sub-questions, each added after the previous result: is the low identity a holdout effect or a data property (Track B, breakdown); is the held-out failure an amplitude error that a per-gene correction can fix (E1, E2); can a correction estimated on the observed source cells improve the transport prediction (E3); is E3 real or noise, and is it really per-gene (S3:2-5, Phase A) [D][C].

## Setup

**Data.** LPS: `train_species.h5ad`, 62,114 cells × 6,619 one-to-one orthologs; mouse LPS6 7,428 / unst 7,625, pig 4,806 / 8,448, rabbit 7,107 / 8,856, rat 9,423 / 8,421 cells (RS/stage0/audit_manifest.json) [R]. Training uses every group except rat LPS6: 52,691 cells, plus 13,208 validation cells from `valid_species.h5ad` (FU/r1_vae_drop02/seed0/config.json) [R]. Rat unstimulated cells stay in training (S1:6-11) [C]. Preprocessing is the scGen authors' file ([F12](F12-scgen-fig5-stage0-and-stage1.md)). Atlas (Track B, E1–E3 only): the v08 cuts, 8,054 cells × 1,000 highly variable genes (HVGs, chosen with Pearson residuals), 4,027 per species (APV/atlas_paper_vae_m1_v08_ood/audit_manifest.json) [R]. The values themselves are non-negative (min 0, max 8.46; APV/atlas_paper_vae_m2_v08_ood/dry_run_split.txt) [R]. m1 holds out the non-classical monocyte (CL:0000875, 365 cells per species); m2 also holds out the monocyte (CL:0000576, 36 per species) (same dry_run_split.txt) [R]. Half of the held-out cells are the out-of-distribution (OOD) evaluation cells and the other half are marked `ignore`: 182 mouse + 183 human (m1), 200 + 201 (m2); the m2 OOD cells include 17 mouse and 21 human monocytes (APV/*/split.csv; dry_run_split.txt) [R]. These checkpoints were trained on 07-21 under Plan C ([F14](F14-july-plans-a-to-d.md)).

**Model.** Every model is the TensorFlow-1 `VAEArith` from scGen's original code (copy in `fasrc:BK/scgen-cellot-ablation/scgen-reproducibility/code/scgen/models/_vae.py`): 6619-800-800-100-800-800-6619 (atlas 1000-…-1000), hidden layers with batch normalization, leaky ReLU and dropout, and a ReLU output, so decoded values are ≥ 0 with exact zeros (`_vae.py:81-119`) [C]. Compared with the June copy on the Mac (`mac:scGen v.s. CellOT/scgen-reproducibility/code/scgen/models/_vae.py`), the FASRC copy only adds progress logging and a per-epoch `training_log.csv`; the network and loss code are unchanged (diff) [C]. The second decoder batch-normalization result is thrown away (`_vae.py:114`), a quirk of the original code that every model here keeps on purpose (`historical_decoder_graph: true`; L23:102-105) [C][D]. The frozen checkpoint itself was trained on 2026-06-22 with the scGen authors' training function (300 epochs, batch 32; `fasrc:BK/scgen-cellot-ablation/scripts/run_stage0.sh`; `fasrc:BK/scgen-cellot-ablation/logs/stage0_20260622_072217.log`) [C][R]. Retrained runs use `SeededVAEArith`, which sets the TensorFlow graph seed (SC/stage0_ae_variants.py:21-61) [C]. Training is a fixed 300 epochs (Adam, learning rate 1e-3) with no early stopping (`early_stop_limit = epochs + 1`, SC/07_stage0_ae_variant_train.py:118-122), and the model is saved after the last epoch (`_vae.py:544-547`) [C]. Runs used the `scgen_tf1` environment (Python 3.7.12, TensorFlow 1.15, scanpy 1.4.4) on 8 CPU cores (FU/r1_vae_drop02/seed0/eval/audit_manifest.json; `fasrc:BK/sbatch/lps/scgen_ae_followup.sbatch`) [R][C].

**Evaluation** (definitions in [F10](F10-monocytes-floor-ceiling-and-v08.md) and [metrics.md](../metrics.md)):

- Transport. LPS uses the Fig. 5 "two-path" prediction ([F12](F12-scgen-fig5-stage0-and-stage1.md)); the atlas uses `single_species_delta` (mean code of human training cells minus mean code of mouse training cells, added to the codes of OOD mouse cells, then decoded) (`evaluation_note` in APV/atlas_paper_vae_m1_v08_ood/metrics.json; `fasrc:BK/atlas-paper-vae/README.md`) [R][D]. "R²" is the squared Pearson correlation of the gene-mean vectors over all genes and over the top-100 marker genes (Wilcoxon test, rat LPS6 vs rat unst on true cells; evaluation only) (SC/04_stage0_fig5_eval.py:147-160) [C].
- Identity ("five-axis panel") on the deterministic reconstruction decode(mu(X)): MSE; paired-cell Pearson²/gene (for each gene, the squared correlation between true and reconstructed values across the same cells, averaged over genes); COD/gene (coefficient of determination, 1 − SSE/SST per gene, averaged); mean-vector Pearson²; per-cell Pearson r (SC/stage0_metric_helpers.py:42-90, 167-200) [C]. LPS slices: held-out rat LPS6 (9,423 cells), seen rat unst (8,421), a 10,000-cell training subsample [R].
- Distribution. MMD (maximum mean discrepancy, a distance between two cell clouds) from HM:66-128: the biased RBF estimator averaged over 50 bandwidths (gamma = logspace(1, −3)), 80 cells per side, 10 repeats, seed 0, on all genes [C]. In the "decoded frame", floor = MMD(decode(mu(target)), target) and ceiling = MMD(decode(mu(source)), target); decoded fgc = (ceiling − model)/(ceiling − floor) (HM:178-185, 290-305), and model/floor = model MMD ÷ floor (SC/09_stage0_ae_followup_study.py:184-185) [C]. Mean JS is the per-gene Jensen–Shannon divergence between 50-bin histograms, averaged over genes (HM:132-155) [C].
- Seeds: one training seed (0) for every trained model. Phase A varies only the MMD subsampling seed (S3:36-41) [C].

Non-standard points: (1) "R²" is squared Pearson, not COD [C]. (2) Paired Pearson² averages only genes that vary in both matrices: 4,673 of 6,619 genes for the frozen model on held-out cells (RS/stage0/recon_identity_extended.json) [R]. That gene set depends on the model: from 4,353 (r1_dae_drop0) to 5,864 (r3_var_b256) genes, and only 416 of 1,000 genes on atlas m1 mouse OOD cells (computed here from the `recon_identity_pergene.csv` files; APV/atlas_paper_vae_m1_v08_ood/recon_identity_extended.json) [R]. So two models' paired Pearson² values are means over different genes. (3) The gene-mean of COD is dominated by a few near-constant genes: held-out LPS COD has mean −0.0199 but median −0.0047 and a minimum of −29 (same file) [R]. (4) MMD is on all genes, while CellOT scores the top-50 markers (cellot.txt, Methods) [P]. (5) For identical clouds and seed, HM gives different values depending on which `ncells` are requested in the same call, because they share one random stream: the LPS floor is 0.11248 with (30, 50, 80) (RS/stage0/metrics.json) and 0.11305 with (80) only (RS/transport_calibration/lps_transport.json; the same 0.11305 is the frozen model's `mmd_at80` in RS/stage0/recon_identity_extended.json) [R]. (6) The paper path uses sampled latents, while all references use mu (L23:98-101; SC/04_stage0_fig5_eval.py:165-209) [D][C]. So every evaluation run draws a slightly different LPS prediction.

## What was done and what came out

### 1. Round 1, 2026-07-26: VAE vs deterministic AE × dropout 0.2 vs 0 (job 35325410, 4 runs)

Design (S1:22-44) [C]: a 2×2 at latent size 100 and batch 32. "VAE" keeps the KL weight alpha = 5e-5 and sampled latents; "DAE" uses z = mu and alpha = 0 (SC/stage0_ae_variants.py:64-68). Hypothesis: "KL/stochastic sampling and dropout cause the paper VAE's cell-specific variance collapse" (S1:23-25). Pass rules (`gates`, S1:45-58; coded in SC/09_stage0_ae_followup_study.py:200-223) [C]: identity improves only if held-out COD > 0 AND paired Pearson² > 0.08618 AND reconstruction MMD < 0.11248; transport is non-inferior only if all-gene R² ≥ 0.897 AND DEG R² ≥ 0.722. These floors equal the frozen checkpoint's 0.907 / 0.742 minus 0.01 / 0.02 [I]. The MMD baseline 0.11248 is the frozen model's floor from the Fig. 5 evaluation (ncells 30/50/80), but the candidates are scored with the identity audit's `mmd_at80` (ncells 80 only), where the frozen model itself scores 0.11305 (SC/09_stage0_ae_followup_study.py:173, 212-213; RS/stage0/metrics.json; RS/stage0/recon_identity_extended.json) [C][R]. So the frozen checkpoint would fail its own MMD rule [I]. No verdict depends on this, because every run also fails COD [R].

### 3. Round 3, 2026-07-27: identity-first auxiliary losses (job 35488948, 4 runs)

Design (S1:67-112; L27:182-212) [C][D]: the "user" chose to keep improving the autoencoder (L27:184-185) [D]. Two extra loss terms (SC/stage0_ae_variants.py:81-153) [C]: a per-gene correlation loss (mean over genes of 1 − Pearson r between input and reconstruction across the cells of a batch) and a per-gene log-variance loss (squared log ratio of true to reconstructed variance). Each is rescaled at every step to 10% of the current reconstruction loss. Both act on all genes, so the evaluation marker list stays unseen (S1:79-83) [C]. The 2×2 runs at batch 256 (8× fewer steps than batch 32; 206 batches per epoch, LG/scgen_ae_followup_35488948_1.out) [R]. Pass rules are relative to the matched control r3_mse_b256 (S1:113-135) [C]: paired Pearson² must rise by ≥ 0.01 and COD must rise; all-gene and DEG R² may drop by at most 0.02. A pre-launch check found the zero-weight loss equal to the original loss (2.9601 vs 2.9601) (L27:206-210); no file of it was found [D]. That scale is about 100 times smaller than the per-cell training loss (about 260; FU/r3_mse_b256/seed0/model/training_log.csv) [R], so the check probably used a toy input [I]. The two loss formulas are algebraically the same (`_vae.py:167-170` vs SC/stage0_ae_variants.py:127-149) [C].

All three also fail a transport guardrail: corr on DEG (−0.040), var on all-gene R² (−0.023), corrvar on both [R]. The log mentions only the corr and corrvar failures (L27:272-273) [D].
- The correlation term "did essentially nothing" on held-out cells; it moved training-cell pairing by only +0.005 (L27:227-231, 330-342; FU/r3_*/seed0/eval/recon_identity_extended.json) [D][R]. The log's explanation, not tested, is that a correlation computed over a batch mixing 4 species × 2 conditions mostly rewards between-group differences (L27:233-243) [D].
- The variance term raised variance kept five-fold (0.039 → 0.213) and lowered reconstruction MMD by 35%, but made COD worse (L27:249-258) [D]; both are confirmed in the table [R]. The −1.08 mean is driven by single genes (one gene at −2,960); the median falls from −0.002 to −0.108, with 87% of genes negative versus 58% for the control (computed here) [R].
- Gene-set check (computed here from FU/r3_*/seed0/eval/recon_identity_pergene.csv) [R]: the variance term makes about 850 more genes vary (5,864 vs 5,013 valid genes), and these enter its paired-Pearson² mean. On the 4,786 genes valid in both runs, its paired Pearson² is 0.0806 vs the control's 0.0892 (Δ −0.0086, about half the table's −0.0183). The correlation term stays at "no effect" on common genes (0.0899 vs 0.0894). Both identity verdicts stand.
- Training curves (FU/r3_*/seed0/model/training_log.csv) [R]: the two runs with the variance term reach their lowest validation loss at epochs 21 and 18 and end 4.9% and 2.1% higher at epoch 300. Each extra term is rescaled to a fixed share of the reconstruction loss (SC/stage0_ae_variants.py:118-125), so this rise is a rise in reconstruction error on validation cells [C][I]. The scored model is again the epoch-300 one.
- The batch-256 control was not under-trained: its all-gene and DEG R² (0.9151 / 0.7790) beat the batch-32 run with the same settings (0.9052 / 0.6938) (L27:260-266; tables) [D][R], and its final validation loss is lower too (258.2 vs 262.1; FU/r3_mse_b256 and FU/r1_vae_drop02 training_log.csv) [R]. The log's "best paper-metric run we have" is slightly off: r1_vae_drop0 has a higher all-gene R² (0.9162) and r3_var_b256 a higher DEG R² (0.7799) [R]. The control's "first non-negative COD in the study" holds for the mean only; its median is −0.0017 [R].
- DEG R² across three "paper-like" runs spans 0.694–0.779 (frozen .742, r1_vae_drop02 .694, r3_mse_b256 .779), far wider than the 0.02 guardrail (L27:268-278) [D][R]. Two of the three use batch 32 and one uses batch 256 [C].
- Not discussed in the log: the Round-3 model/floor ratios (1.47–1.59) lie below the whole Round-1 range (1.73–1.88), the control included [R]. So the ratio does change with training settings, which weakens the argument used to skip Round 2 [I].
- Decision: "No winner ... Either fix the loss to be group-stratified (Round 4) or accept that within-slice cell identity is not reachable from this objective family at z=100 on this dataset" (L27:280-285) [D].

## Verdict

- Firm [R]: no Round-1 or Round-3 model passed its pre-registered rules. Firm in direction but single-seed [R][I]: removing dropout, or adding the variance term, trades distribution metrics (MMD, JS, zeros, variance kept) against paired identity and COD; these changes are far larger than the one measured rerun difference (paired Pearson² +0.0008, COD +0.004). Comparing on genes valid in both runs halves the variance term's paired-Pearson² loss but does not remove it (§3). The per-gene correlation term had no measurable effect on held-out cells (Δ paired Pearson² −0.0013; +0.0005 on common genes). No trained model's LPS two-path prediction beats the decoded untreated rat cells (all fgc < 0).
- Firm [R]: on LPS, held-out within-group pairing equals that of seen groups at n = 180 (0.100 vs 0.108). The gap between mixed seen cells and the held-out group at n = 180 (0.235 vs 0.100) is almost all composition (0.127 of 0.135). On the atlas the held-out deficit is real: 0.32 human and 0.20 mouse, against 0.48 for seen groups.
- Firm [R]: the paper VAE's decoder keeps little within-group variance: about 4% on LPS rat groups, and 29–30% (human) and 3–7% (mouse) on atlas OOD slices, counting genes that vary.
- Firm [R]: devar's MMD gain is not per-gene. At the headline cell (cap 5, 80 cells), in absolute MMD, gene-shuffled factors recover 97–98% and one global factor 97–99% of it on the atlas, and both beat it on LPS; across caps 2, 5 and 10 (80 cells) the per-gene vector never beats one global factor by more than about 3% of its gain (computed here).
- Not shown [I]: (a) that dropout itself harms pairing, because the dropout-0 models were over-fitted at epoch 300; (b) that a calibration fitted within single seen groups would fail; (c) anything about training-seed robustness, since every trained model is one seed; (d) whether more capacity, early stopping or a group-stratified correlation loss would help (never run); (e) that devar is useful, given the worse JS, likely negative values and the fact that it changes no model; (f) anything about the hub CellOT autoencoder, because Phase B never ran.
- Status "did not work" answers the study question (S1:2-4) [I]: no model improved cell-level reconstruction without losing something else, and the one distribution gain without mean cost (devar) changes no model, is not per-gene, worsens atlas JS and does not improve the LPS model/floor at the headline setting. - Strength: the diagnostics (§§4–6) rest on large slices or 5 draws and reproduce from the files, so they are moderate to strong. The training interventions (§§1, 3) are single-seed with wide run-to-run spread, so they are weak. E3/Phase A is strong for the negative conclusion (5 seeds × 3 caps, tight spread) and says nothing about any positive one.

## Problems in how it was done

- **"Pre-registered" cannot be checked.** S1 and S3 were first committed on 07-30, after every run (`conny@4244985`), the BK `specs/` folder is empty (FASRC ls, 10-20), and the committed S1 already contains the Round-1 outcome (S1:60-66) [G][R]. The Round-1 configs of 07-26 13:41 prove only that the four variants were fixed before training; they do not contain the pass rules [R]. The claim rests on the log (L27:9, 666) [D].
- **One training seed everywhere.** Run-to-run spread of DEG R² (0.694–0.779) is about four times the 0.02 guardrail (L27:268-278) [D][R]. Every "no effect" or "worse" verdict on a single run is fragile; only the large identity changes (dropout 0, variance term) clearly exceed the spread [I].
- **Round-1 floors came from a single run.** The transport floors are the frozen checkpoint's values minus a margin [I], and the same recipe retrained fails the DEG floor (0.694 < 0.722) [R]. So a dropout-0.2 run could fail transport by chance [I]. The MMD baseline (0.11248) also comes from a different MMD call than the column it is compared with; the frozen model scores 0.11305 in that column (§1) [R].
- **Paired Pearson²/gene is averaged over a model-dependent gene set** (4,353–5,864 of 6,619 genes on held-out LPS cells) [R]. The Round-1 rule "> 0.08618" and the Round-3 rule "+0.01 over the control" compare means over different genes. On genes valid in both runs, the variance term's loss shrinks from −0.018 to −0.009 (§3) [R]. No verdict flips, but sizes are overstated.
- **Fixed epoch budget with no early stopping.** The dropout-0 validation loss bottomed at epoch 12 and rose ~17% by epoch 300 (FU/r1_*_drop0/seed0/model/training_log.csv) [R]. H2 ("dropout removal ... rejected") is therefore confounded with over-fitting [I]. The two Round-3 runs with the variance term also bottomed early (epochs 21 and 18) and ended 2–5% higher (FU/r3_*var*_b256/seed0/model/training_log.csv) [R].
- **COD summarized by its gene-mean.** Single genes reach COD −29 to −2,960 (LPS) and −451 (atlas) [R]. The Round-1 rule "COD > 0", the "first non-negative COD", B3 and C2 all rest on this outlier-prone mean; medians tell the same direction for dropout 0 and the variance term, but not the same size [R][I].

## Terms used here

- **frozen (paper) checkpoint**: the Stage-0 TF1 model at `scgen-reproducibility/models/scGen/species/rat/scgen`, trained on 2026-06-22 with the original `VAEArith` class and the authors' training function ([F12](F12-scgen-fig5-stage0-and-stage1.md)).
- **r1_vae_drop02, r1_dae_drop0, …**: Round-1 runs (VAE or deterministic AE, dropout 0.2 or 0). **r3_mse_b256, r3_corr_b256, r3_var_b256, r3_corrvar_b256**: Round-3 runs at batch 256 with neither, one or both extra loss terms. S1:77 calls the control "run A", and the canvases label the four runs A–D ("Arm C" = r3_var_b256).
- **DAE**: here a deterministic autoencoder (z = mu, KL weight 0), not a denoising autoencoder.
- **vae_aux; corr_fraction / variance_fraction**: VAE with extra loss terms, each rescaled every step to that fraction (0.10) of the current reconstruction loss.
- **matched-batch control**: r3_mse_b256, the reference for every Round-3 rule.
- **`gates`** (repo term): the spec's pass/fail rules, here the "identity" rule and the "transport non-inferiority" rule.
- **historical decoder graph**: keeping the original code's discarded second batch-normalization in the decoder.
- **five-axis identity panel**: MSE, paired Pearson²/gene, COD/gene, mean-vector Pearson², per-cell r on decode(mu(X)) (AG:87-97).
- **variance kept / variance retention**: median over genes of var(reconstruction)/var(truth).
- **decoded fgc, decoded denominator, model/floor**: see Setup; the denominator is ceiling − floor.
- **`north-star`** (repo term, AG:30-45): the repo's headline metric, `frac_gap_closed_decoded`.
- **two-path; single_species_delta**: the LPS Fig. 5 prediction rule and the atlas mean-shift rule.
- **Track B**: the identity audit of the atlas paper-VAE checkpoints. There is no "Track A" or "Track C" in the record; B1–B4, C1–C3 and E3a–E3d are finding labels in L27.
- **composition effect / held-out deficit**: mixed-cell score − single-group score, and seen-group mean − held-out score (§5).
- **E1, E2, E3**: inference-only checks: variance kept; affine recalibration; correction of saved transport predictions.
- **seen-fit affine; oracle_affine_LEAKY; source_affine; source_devar ("devar"); oracle_devar_LEAKY**: the correction variants of E2/E3. "LEAKY" means fitted on the held-out target.
- **cap**: maximum allowed devar scale factor (2, 5 or 10).
- **calibrated frame / own frame**: floor and ceiling recomputed after applying the same correction to the reference clouds.
- **fallback genes (`frac_fallback`)**: genes with no measurable reconstructed variance; they get scale 1.0 (or slope 1.0).
- **Phase A / Phase B; A1, A2, A3**: S3's confirmation stages; A1 = gene-permuted scale vector (10 permutations), A2 = one global scale, A3 = check that mean R² is unchanged.
- **metric seed**: seed of the MMD subsampling only; nothing is retrained.
- **m1 / m2**: atlas cuts holding out CL:0000875, or CL:0000875 + CL:0000576.
- **canvas**: a Cursor "canvas" file (`*.canvas.tsx`) used to display metrics; not in any repo, only in the Cursor project folder on the FASRC home.

## What the package needs from this

Nothing here is a model worth reproducing: no variant won, every run is one seed, and the dropout-0 arm is over-fitted. The evaluation side is useful. The hand-built package's `scGenModel` is meant to wrap the same `scgen.VAEArith`: its `setup()` builds one, but `train()` and `predict()` are still stubs and `setup()` reads a misspelled attribute (`self.x_dimensions`) (`josh@scgen-model-impl:src/speciesot/speciesot_core.py:212-294`) [C].
