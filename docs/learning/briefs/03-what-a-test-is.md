# Brief: A folder named Tests is not a test

- **Learning objective.** You can tell a function pytest will collect from a script that only lives in a folder named Tests.
- **Audience.** You can run notebooks. Package layout, abstraction, and pytest are new. You lose the thread of which notebook you already ran, and of when to open scgen or cellot versus our code.

- **Structure.** s01 hook. Two files sit in `Tests/`. One of them is not a test. s02 pytest collects a function whose name starts with test_. Show the MMD function appearing in a collection list, and test_model.py contributing nothing. s03 what the MMD test actually checks. - **Misconception to break.** test_model.py and e24_replica.ipynb are tests because they live in Tests/.

A collector arrow enters each file and keeps only names that start with test_. test_evaluation.py yields one box, test_mmd_is_zero_for_identical_distributions. test_model.py yields an empty list. The notebook sits outside the collector. Inside the kept box, two identical point clouds go into `MMDEvaluation.evaluate` and a score comes out next to `pytest.approx(0.0)` (`zip:src/speciesot/Tests/test_evaluation.py:19-22`).
