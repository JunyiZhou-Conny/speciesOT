PHASE 4 — BCG PREDICTION (4 model x flavor combos)
================================================================================

WHAT YOU DO
   /n/home01/jzhou1125/miniforge3/envs/analysis/bin/python -m nbconvert \
       --to notebook --execute --inplace \
       --ExecutePreprocessor.timeout=1800 \
       speciesOT/baseline/analysis/17_bcg_prediction.ipynb

INPUT NEEDED
   The 4 trained model.pt files from Phase 2.
   The 2 BCG-aligned datasets from Phase 3.
   The 2 atlas-full datasets from Phase 1 (used by scGen to recompute code_means).

OPERATIONS PERFORMED
   For each (flavor, model):
   - Load atlas dataset to define input_dim
   - Load trained model from cache/model.pt
   - For scGen: compute code_means = mean latent vector per condition (mouse, human) on training data
                shift = code_means['human'] - code_means['mouse']
                pred = decode(encode(BCG_mouse) + shift)
   - For IMPACT_CellOT:
                Load AE encoder/decoder from atlas_full_<flavor>/scgen/cache/model.pt
                pred = decode(g.transport(encode(BCG_mouse)))
                where g is the trained OT map
   Then: build joint UMAP per flavor (atlas mouse + atlas human + BCG mouse + scGen pred + IMPACT pred)

EXPECTED OUTPUT
   cellot/cellot_gpu/datasets/speciesot-human-mouse-hvg/bcg_predicted_human_via_scgen_seurat_v3.h5ad
   cellot/cellot_gpu/datasets/speciesot-human-mouse-hvg/bcg_predicted_human_via_impact_cellot_seurat_v3.h5ad

       Each: 1,406 cells x 1000 genes (predicted human gene expression)

================================================================================
TROUBLESHOOTING
================================================================================

"BlockingIOError: Unable to lock file"
   Two processes writing same .h5ad. Wait and re-run, or kill the other process.

"cannot safely cast non-equivalent float32 to int64"
   raw counts must be int32 for seurat_v3 / pearson_residuals. Check Phase 1 cell 5
   that .layers['counts'] is int32, not float32.

"BioMart 403 / connection timeout"
   BioMart goes down occasionally. Cached results live at:
       scripts/.biomart_ortholog_cache.csv
       scripts/.bcg_symbol_to_ensmusg.csv
   If both exist, the pipeline runs without hitting BioMart.

"input_dim missing" when loading IMPACT_CellOT model
   Pass input_dim=50 (latent dim, not gene dim). See Phase 4 code in notebook 17.

"r2 values look too low"
   The r2-* columns in evals.csv are Pearson r, NOT R-squared.
   Square them after loading. Notebooks 13/14/18 do this automatically.

"IMPACT data-space imputed.h5ad is 50-d, expected 1000-d"
   Re-run evaluate.py with --embedding ae flag. Without it, decode() is silently skipped.


================================================================================
KEY METRICS SEMANTICS (READ ONCE, REMEMBER FOREVER)
================================================================================

evals.csv 'metric' column meanings:
   r2-means              ->  Pearson r between predicted and target gene means.  SQUARE for R^2.
   r2-stds               ->  Pearson r between predicted and target per-gene std.  SQUARE for R^2.
   r2-pairwise_feat_corrs->  Pearson r between predicted and target gene-gene correlations. SQUARE for R^2.
   mmd                   ->  Maximum Mean Discrepancy. Lower = better. NOT squared.

evaluation 'where':
   latent_space          ->  metrics computed on 50-d AE latent codes (fast, OT-focused)
   data_space            ->  metrics computed on decoded 1000-d gene expression (interpretable, slower)

evaluation 'setting':
   ood                   ->  evaluate on cells the model never saw during training
   iid                   ->  evaluate on cells from the same distribution as training (random subset)
